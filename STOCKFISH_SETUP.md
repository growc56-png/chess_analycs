# Установка и настройка Stockfish

Сайт использует официальный движок Stockfish через UCI и библиотеку `python-chess`.

## Установка Stockfish 19

Из корня репозитория выполни:

```powershell
python scripts/install_stockfish.py
```

Установщик выбирает подходящий официальный универсальный архив Stockfish 19 для Windows, Linux или macOS, проверяет размер и SHA-256 по метаданным официального GitHub-релиза и извлекает движок вместе с NNUE-сетью. Архив не хранится в репозитории.

Релиз закреплён на теге `sf_19`, чтобы автоматическая установка не меняла версию неожиданно. Чтобы перейти на будущий релиз, сначала обнови тег/контрольные суммы и проверь его на тестовых партиях.

## Переменные окружения

Скопируй корневой `.env.example` в корневой `.env` и укажи настоящий `DATABASE_URL`. Файл `.env` нельзя добавлять в Git.

`STOCKFISH_PATH` необязателен: без него приложение ищет локальную сборку в корне проекта, затем движок `stockfish` в системном PATH. При нестандартном расположении укажи абсолютный путь.

Параметры движка:
- `CHESS_ENGINE_THREADS` — потоки полного анализа; по умолчанию выбирается автоматически с резервом CPU для ОС.
- `CHESS_ENGINE_HASH_MB` — Hash полного анализа, по умолчанию 256 MiB.
- `CHESS_BOT_ENGINE_THREADS` и `CHESS_BOT_ENGINE_HASH_MB` — более лёгкий профиль игры с ботом.
- `CHESS_ANALYSIS_DEPTH` и `CHESS_ANALYSIS_TIME` — быстрый проход по партии.
- `CHESS_DEEP_ANALYSIS_DEPTH`, `CHESS_DEEP_ANALYSIS_TIME` и `CHESS_MAX_DEEP_ANALYSIS_MOVES` — повторная проверка критических ходов.
- `CHESS_BRILLIANT_ANALYSIS_DEPTH` и `CHESS_BRILLIANT_ANALYSIS_TIME` — отдельный бюджет проверки жертв.
- `CHESS_MAX_PENDING_ANALYSES` — ограничение ожидающих/выполняющихся задач анализа на один процесс.

Не увеличивай Threads, Hash и время анализа без учёта RAM и CPU хостинга. Несколько worker-процессов умножают расход ресурсов.

## Проверка

После запуска backend открой:

```
GET /api/engine/status
```

Ответ показывает обнаруженную версию движка, активный профиль потоков и Hash. Если `available=false`, проверь путь, права исполнения файла и совместимость сборки с ОС.

Для анализа качества движка запусти регрессионные тесты:

```powershell
cd backend
python -m pip install -r ../requirements.txt
python -m unittest discover -s tests -v
```
